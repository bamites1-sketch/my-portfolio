# Beamlak — Developer Portfolio

Ultra-premium developer portfolio for Beamlak, Software Engineering student at Wollo University.

## Stack
- React + Vite
- Tailwind CSS v4
- Lucide React (icons)
- Axios (GitHub API)
- CSS animations (scroll reveal, blobs, typed text)

## Getting Started

```bash
npm install
npm run dev
```

## Deploy to Vercel

```bash
npm run build
# then push to GitHub and connect to Vercel
```

## Features
- Live GitHub API integration (repos, profile, stats)
- Animated hero with typewriter effect
- Scroll-reveal animations throughout
- Glassmorphism project cards with hover effects
- Interactive skills section with animated progress bars
- GitHub stats dashboard with language distribution
- Contact form with mailto integration
- Fully responsive (mobile-first)
- Dark mode by default
